# 🌍 Country Explorer

Country Explorer is an interactive geography game and exploration website.

## 🎮 Features

- 🗺️ Explore countries
- 🌍 Interactive globe
- 🔎 Search countries
- 🎲 Random country
- 🏳️ Flags
- 🏛️ Capitals
- 💰 Currencies
- 👥 Population
- 🎮 Geography quiz
- 🟢 Easy difficulty
- 🔵 Medium difficulty
- 🟠 Hard difficulty
- 🔴 Impossible difficulty
- 1️⃣ 2️⃣ 3️⃣ 4️⃣ randomized answers
- 📊 Game progress bar
- 🏆 Scores and statistics
- ⭐ XP system
- 🔥 Streak system
- 🏅 Achievements
- 💡 Fun Fact of the Day
- 📱 Mobile-friendly design

## 🚀 How to Run

Open `index.html` in a web browser.

No installation or external software is required.

## 🎯 Goal

Explore the world, improve your geography knowledge, and challenge yourself across increasingly difficult game modes.
